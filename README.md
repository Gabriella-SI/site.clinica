# Health Haven Pages

Crie uma landing page completa, profissional e de alta conversão para uma clínica chamada **[NOME DA CLÍNICA]**, localizada em **[CIDADE/UF]**.

O objetivo principal da página é apresentar a clínica, transmitir confiança e transformar visitantes em pacientes, principalmente através de **agendamentos pelo WhatsApp**.

A página deve ter aparência de um projeto desenvolvido por uma agência profissional de marketing e web design para o segmento de saúde. NÃO quero um template genérico, uma página simples ou aparência de site gratuito.

### CONCEITO VISUAL

A identidade deve transmitir:

* confiança
* segurança
* acolhimento
* profissionalismo
* sofisticação
* cuidado
* tecnologia

Utilize uma estética clean e premium.

Paleta sugerida:

* Branco/off-white como base
* Azul profundo ou azul-petróleo como cor principal
* Azul-claro ou verde suave como cor secundária
* Cinza-escuro para textos
* Uma cor de destaque para CTAs

Utilize bastante espaço em branco, bordas arredondadas, sombras suaves e imagens profissionais.

A interface precisa parecer moderna sem exagerar em efeitos.

Fonte: Inter, Manrope ou outra fonte sans-serif moderna.
